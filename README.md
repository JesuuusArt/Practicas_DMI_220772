## Detalles de Práctica #2: Contador Funcional

La segunda práctica consiste en desarrollar una aplicación móvil con Flutter que implemente un contador funcional con las siguientes características:

- ✅ Uso de **Stateful Widgets** para manejar estado
- ✅ Implementación de **botones flotantes** para interactividad
- ✅ Sistema de **colores dinámicos** basado en el valor del contador
- ✅ Creación de **widgets personalizados** (CustomButton)
- ✅ Aplicación de **fuentes personalizadas** (Google Fonts)
- ✅ Manejo de **eventos y setState()**

## Cómo Ejecutar

1. **Navega a la carpeta del proyecto:**
   ```bash
   cd hello_world_app
   ```

2. **Instala las dependencias:**
   ```bash
   flutter pub get
   ```

3. **Ejecuta la aplicación:**
   ```bash
   flutter run
   ```
