# Iconos de la App - Estructura Temporada

Aquí coloca cada icono de temporada. Sugerencia:

- `principal/` — icono azul del formato principal
- `halloween/` — icono naranja
- `navidad/` — icono rojo-verde

Luego reemplaza los iconos en:
- Android: `android/app/src/main/res/mipmap-*/`
- iOS: `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- Web: `web/icons/`

Aún no hacemos nada con ellos: esto es solo la estructura de placeholder.
